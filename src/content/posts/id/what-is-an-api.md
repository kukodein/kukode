## Apa itu API?

API adalah singkatan dari **Application Programming Interface**. API adalah sekumpulan aturan dan protokol yang memungkinkan aplikasi perangkat lunak yang berbeda untuk berkomunikasi satu sama lain.

## Cara Kerja API

API bekerja melalui siklus request-response sederhana:

1. **Request**: Klien mengirim permintaan ke endpoint API
2. **Pemrosesan**: Server memproses permintaan
3. **Response**: Server mengirim kembali data dalam format terstruktur

## Kesimpulan

Memahami API sangat penting bagi setiap developer atau pemilik bisnis yang ingin membangun aplikasi modern.
